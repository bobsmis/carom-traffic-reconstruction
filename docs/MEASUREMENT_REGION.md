# 有效测量区域（ROI）

## 目的与边界

舍弃远处像素与几何信息不足的道路区段，不再为全画面所有小目标创建车辆轨迹。这里限制的是**空间测量区段**，没有删除视频时间段或改变播放时间轴。

米制阈值依赖场景标定；当前用户素材仍为假设标定，控制点 RMSE 约 13.83 px。限制范围只是减少低质量输入，不构成尺寸、速度或绝对位置精度认证。

## 当前默认值

配置位于 `configs/user_bridge_traffic.json` 的 `measurement_region`，非按某个车辆 ID 手工挑选：

| 条件 | 默认值 | 含义 |
|---|---|---|
| 道路地面多边形 | x=-18..18，y=0..100 m | 纵向扩为原来两倍；八条名义车道外再各留 4m 边距；不是相机距离 |
| 相机地面距离 | ≤150 m | 同步放宽，避免旧距离条件截断扩大后的 ROI |
| 检测框像素范围 | 宽≥24、高≥24 px | 坐标恢复到原始裁剪画面后判断，非模型缩放图尺度 |
| 掩膜面积 | ≥400 px² | 排除薄碎轮廓及过小目标 |
| 假设像素噪声 | σ=2 px | 用于局部投影敏感性评估 |
| 条件投影 σ 上限 | ≤2.5 m | 原为 0.75m，为扩大覆盖主动放宽；不包括标定误差，不代表远处同样精确 |
| 检测上下文边距 | 96 px | 保留边界车辆轮廓，不把 ROI 外直接涂黑送入模型 |

阈值在运行前固定，同一规则应用全部帧。未为了零交叠临时改动车辆坐标、车道归属或尺寸。

## 执行顺序

1. 由统一相机模型将地面区域投影回原图。只将其外接矩形与上下文边距送入本地检测器，恢复所有框/掩膜到原始画面坐标。
2. 对候选应用像素尺寸、掩膜面积、地面区域、距离及投影敏感性门控。图像裁剪内部边界截断的候选也排除，避免拿残缺轮廓估尺寸。
3. 候选筛选中的轮廓底部点只作为 ROI 预筛探针，**不作为最终车辆位置**。通过筛选后才进入光流/掩膜跟踪和体积框拟合。
4. 对拟合底面中心再次进行同样的地面门控；对 Kalman 输出的位置也检查，避免光流/滤波把车辆外推到区外后仍绘制。
5. 区外轨迹停止公开输出；跟踪器内部可保留到最大失联帧数，短暂返回时仍有机会匹配原 ID。超过阈值退役；ID 不循环复用。没有把区外预测标为区域内测量。
6. 区内但因遮挡、截断或未知航向尚未定位的对象仍明确显示待确认；不是所有 ROI 内检测都天然满足体积定位条件。

检测输入保留矩形上下文，因此模型可能产生矩形内、有效多边形外的候选；这些候选记录排除原因，不进入新轨迹。缓存模式仅用于回归已有本地观测，属于全图历史候选→ROI 筛选，审计会与实际裁剪推理区分。

## 展示与可审计数据

- 原始画面保持原样。
- 检测图及 BEV 用绿色线标出名义测量多边形，区域外暗化；像素/距离/敏感性条件可能进一步减少区域内可接受目标。
- `rejected_candidates`：进入跟踪前排除的候选框、原因和诊断。
- `excluded_objects`：已有 ID 因有效区域门控停止公开输出的条目。
- `objects`：真正显示的区域内检测/预测/待确认对象。有效坐标必须满足全部地面条件。
- 数量守恒分别检查：原候选=接收候选+排除候选；接收候选=公开观测对象+门控后停止输出的观测对象。
- 区域外车辆不再要求在检测图/BEV 中一一画出；原始素材中的车辆当然仍可见。此差异是明确的测量范围限制，而不是漏画或隐藏失败指标。

- 原始用户视频前 240 帧，本地 YOLO **重新对 ROI 裁剪画面推理**，未使用历史检测缓存，也没有 LLM 处理视频数据。

- 检测器产生 4127 个候选对象帧，跟踪前排除 1678 个：超距离 530、区域外 564、检测上下文边界截断 556、像素范围过小 28。
- 已有轨迹另有 249 个对象帧停止公开输出（区域外 245、超距离 4），内部仍按正常寿命管理身份。
- 公开输出：2086 个有效几何观测对象帧、12 个预测对象帧、356 个待确认对象帧。有效定位全部通过区域检查。
- 27 个全局 ID；没有 IDF1 真值验证，不将此数解释为真实车辆数。
- 第 132 帧验证图：13 个区域内对象，12 个有效定位，1 个因边缘截断待确认。公开有效底面交叠面积超过 0.1 m² 的对数为 0；筛选后减少交叠不代表全场景精度已经达标。
- 视频时间轴与帧数保留，H.264 版本仅做尺寸缩放和编码。
