## 阻止正式发布的主要问题

1. 当前相机焦距和 4 对地面点是旧配置假设值。刚体相机模型的控制点重投影 RMSE 为 **13.83 px**，最大约 **20.25 px**，无独立实测检查点。更换算法不会自动把这些假设变成真实标定。
2. 分割器仍为通用 YOLO，不是作者微调的 Mask R-CNN；远处低分辨率轮廓、截断和遮挡仍影响定位和车体尺寸。
3. 尺寸先验、有界支撑平面求解与光流深度测速存在明确实现差异，详见方法对齐文档；尚未进行真实尺寸/速度真值检验。
4. 当前 BEV 背景由原视频多帧中值逆透视得到。道路外高物体的拉伸是平面假设的结果，背景残留与场景标定仍待改善；它不是地理测绘底图。
5. 8 条车道仍以名义宽度定义，仅作位置语义注释；尚未完成同场景实测车道拓扑注册。

## 下一阶段优先级

先建立可验证的同场景相机—道路标定和独立检查点，再检验车道归属、车体尺寸、定位/速度误差与真实 ID 连续性；然后决定检测器适配。待核心精度通过再切换正式界面和汽车贴图。避免再次用展示上的整齐代替算法验证。
