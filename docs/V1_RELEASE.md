# V1.0 RC1：问题分析、处理与验收

## 交付范围

固定单目离线视频 → 本地检测/分割 → 全局 ID、短时预测 → 道路平面模型 → 三阶段图、同步视频、逐帧 JSON。
保持 React/Vite 与 FastAPI 分离。最终三维场景重建不在本版范围。
当前验证覆盖首 240 帧、55 个轨迹编号，不等同于所有视频和场景均已验收。

## 问题与整体处理

| 问题 | 根因 | V1 处理与边界 |
|---|---|---|
| 八车道被压到四条 | 世界纵横轴混用、轨迹聚类代替车道几何 | 按相机地面坐标注册八条中心线，明确纵横轴 |
| 车道归属错误 | 装饰性道路照片的标线坐标与标称八车道世界坐标不一致 | 用同一套 3.5 米标称尺度生成八车道示意底图，不把另一条道路的照片当测量真值 |
| 远近车辆堆在端点 | 有限线段投影使用 clamp 把超范围点压到端点 | 端段外推，扩大显示范围，保留每个原始地面坐标 |
| 来回行走 | 测量抖动与车距强制位移相互冲突 | 方向先验约束纵向进度；撤掉强行后推和隐藏；记录每次修正量 |
| 车辆相互堆叠 | 多车强制吸附同一中心线、重复预测、尺寸估计偏差 | 保留横向测量分离，全局轨迹预测去重；所有框体做凸多边形相交诊断，不用隐藏或挪动车辆伪造零重叠 |
| 漏帧、闪烁 | 只绘制当前检测结果 | 已有全局跟踪与最多 18 帧恒速预测，区分实测与预测；原检测漏检仍需模型精度验证 |
| 车道变化 | 单个 ID 终身固定车道 | 显示车道按显示坐标几何归属；跟踪车道连续 8 次观测后切换，分别存为 map_lane_id / map_tracking_lane_id；差异标记 association_pending，路外位置标记 outside_road_model，不用吸附坐标消除差异 |
| 双向朝向错误 | 把噪声速度直接当朝向 | 逐车道明确方向；异常方向待独立检测，先验不当作真值 |
| 图标拉伸 | 地图横纵独立缩放 | 全视图单一像素/米比例，车辆 footprint 按估计米制长宽绘制 |
| 体积框失真 | 把二维外接框当真实三维框 | 分割接地宽度与类别先验融合；输出估计来源，保持“估计框”标识 |
| 图中编号/数量不同 | 渲染层隐藏对象、旧前端读取其他示例 | 同一帧记录驱动各面板，V1 独立输出/API，旧页明确独立 |
| 参数精度与可复用性 | 无实测控制点，道路平面假设有限 | 配置驱动复用代码，每个新场景重新标定；速度和位置只报估计 |
| 验收可信度 | 展示图与定量证据混淆 | 原观测不变断言、源文件哈希、输出逐帧记录、冲突报告、单元/API/构建检查 |

## 验证结果

以本次实际 `outputs/release-v1/diagnostics.json` 为准：

- 240 帧、5935 条对象记录；八条车道均有观测。
- 映射字段缺失 0，渲染主动隐藏 0，投影中心越出总视图 0。
- 模型纵向进度逆向步数 0。这是运动先验生效，不是独立实测轨迹准确率。
- 29 帧各存在 1 对 footprint 相交，共 29 对次；已保留冲突 ID。
- 5935 条对象记录中，5058 条显示/跟踪车道一致，421 条关联待稳定，456 条落在当前道路模型外。这里“一致”是内部模型一致性，不是实际车道准确率；路外记录仍显示并标问号，待标定与边缘车辆复核。
- 原始 ID、检测框和地面测量保留，未用排队算法重写真实位置。
- 纵向模型修正量 P95 为约 1.34 米；此值是模型与原测量的差异，不是定位误差。
- 23 项后端测试通过，前端构建与 lint 通过。

因此版本标记为 **1.0 RC1 验收候选版**，不是“全问题解决”的精度认证正式版。
剩余验收重点：冲突对次归因、遮挡关联真值、远处落地点、实际车道归属、独立控制点定位误差。

本次发布复用 `outputs/user-bridge-traffic-corrected/frames.jsonl` 中已完成的本地 YOLO/跟踪观测，重算道路模型并重新渲染，不重复执行相同检测推理。审计记录源观测文件 SHA256。

## 接口

- `/api/pipeline/diagnostics`：验收指标和限制。
- `/api/pipeline/frames/{frame_index}`：单帧观测、模型修正、ID、候选/最终车道及冲突编号。
- `/api/pipeline/validation`：三阶段验证 PNG。
- `/api/pipeline/video`：移动端预览视频。
- `/api/pipeline/audit`：素材、权重、配置与源观测哈希。

V1 页面默认同源代理 `/api`，移动设备访问时避免 `localhost` 指向手机自身。
旧的 `/api/scene` 和 `?legacy` 是历史静态演示，不作为本次验收输入。
