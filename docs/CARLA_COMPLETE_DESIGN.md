# CARLA 单目交通重建完整设计与验收协议 v1

状态：完整架构设计 + 基础模块实施中；不是高精度版本验收声明。

## 1. 可验证需求

R1 当算法运行时，输入仅为 RGB、帧时间戳、相机 K/畸变/R/t、静态道路几何以及预先冻结的模型和通用参数。

R2 当评估器运行时，算法输出已经封存；评估器可读 truth，但不回写预测。预测、代码、配置、权重、输入和真值分别记录摘要。

R3 当车辆靠近车道边界时，返回候选车道及不确定状态，不改变测量位置。车道方向只能作为诊断，不强制反转速度。

R4 当目标遮挡时，显式输出 predicted、预测年龄及协方差；超过限值结束发布。检测漏失和遮挡不靠真值补齐。

R5 当开展精度验收时，覆盖率、漏检、关联失败与精度一起报告，拒绝仅筛选成功案例的成绩。

R6 当使用测试集时，配置和权重已冻结；根据该集结果修改算法后，该集降为开发集，新生成独立测试集。

## 2. 反作弊边界

允许：相机安装测量，静态 OpenDRIVE 车道中心/边界，RGB 可观测内容，通用车型先验，开发集监督训练（单独声明）。

禁止运行时输入：actor_id、车辆位姿/速度/尺寸、实例真值/深度、Traffic Manager 状态、生成种子、出生顺序、路线计划。算法进程不导入 carla、不连接 2000/8050 端口。

禁止场景配合：按算法误差修改车辆位置、把场景全部换为检测容易的车型、调相机只留下容易目标、删除失败帧、不报告远处排除车辆。

禁止显示伪修正：吸附车道中心、依据真值改方向、碰撞后挪车、使用固定虚构尺寸冒充逐车估计、用真值补漏检。

当前仅程序路径/文件组织隔离，尚未实现 OS 级隔离。正式运行目标：算法容器挂载 input、模型、代码只读，output 可写，不挂载 truth，关闭网络；评估容器单独读 truth 和已封存 output。日志记录实际权限和进程退出码，不将文件夹分离称为安全沙箱。

## 3. 完整模块

### 数据与标定

采集端同步仿真帧和 RGB。道路 X=CARLA Y，Y=CARLA X−100，Z=CARLA Z，转换为右手系。基准零镜头畸变；新非零畸变场景要先增加去畸变流程及测试。标定检查包含旋转正交性、正深度、单位一致性、独立道路控制点；往返投影仅证明数值一致性。

### 感知与图像关联

本地实例分割 → 重复候选合并 → 多目标关联。关联使用图像位置、掩膜/外观、光流和运动预测。输出 tentative/confirmed/coasting/retired 状态。全局 ID 在一次运行中单调分配、不复用。有效 ROI 和像素阈值冻结，并保留被排除对象计数。

### 几何与刚性尺寸

使用同一 K/R/t 投影，结合多帧轮廓、地面接触约束和运动方向拟合每车刚性长宽高。下一阶段联合优化窗口内位姿与共享尺寸，采用稳健残差、遮挡权重和通用尺寸弱先验。低视差、静止、截断时允许尺寸不确定；信息不足不宣称真实体积已测得。锁定尺寸前报告置信度；锁定后新证据严重矛盾时启动多帧重估，不逐帧跳变。

### 运动与道路

道路平面 CV/CTRV 模型（直行/转弯）按证据融合，协方差随预测时间增长；物理约束使用通用加速度范围，不读取 TM 实际速度。车道作为静态几何分类，边界附近报告候选，不修正车辆横向位置。真实变道保留，不以“平滑”抹掉。

### 渲染与客户端

视频、标注、BEV 共享同一帧/ID 状态表。没有有效几何的 ID 明确列在待定位区，不凭空在平面生成位置。显示插值仅影响渲染，不覆盖算法测量。原生 Qt 四窗口客户端为独立后续模块，不使用 WebUI；Unity 输出暂留适配接口。

## 4. 数据集协议

现有 160 帧基准已被观察并用于诊断，明确归为 development，永不作为最终盲测。

后续生成前登记场景矩阵：

|分组|内容|用途|
|---|---|---|
|开发|直行稀疏/密集，多个车型，两个视角|误差分解与训练/调参|
|验证|独立种子、不同间距、遮挡和停车|选择统一配置|
|封存测试|独立种子与车型组合、变道、光照变化|一次冻结验收|

每组按整段场景划分，非相邻帧随机切分。测试场景生成策略先登记；失败场景原样保存。至少区分近/中/远距离、遮挡程度、车型和直行/变道。当前简化八车道直路之外的泛化不得由当前结果推断。

## 5. 评估器

阶段 A（已实施）：预测图像框与投影真值框在图像域匹配，一对一分配，IoU≥0.3，唯一性间隔≥0.1。绝不按地面位置误差配对；歧义样本保留数量。仅作为 proxy 诊断，不产生验收通过标记。

阶段 B（待实施）：验证实例颜色编码与 actor_id 对应关系，计算遮挡可见面积。逐车建立可见真值 ID。可用独立单车采集进行编码标定，但其结果只能用于评估端。视锥内不等于可见。

阶段 C（待实施）：HOTA/IDF1/ID switches/fragmentation，定位覆盖率，横向/纵向/P95 误差，车道归属准确率，方向与速度误差，逐维尺寸误差与稳定性。区分 observed/predicted，bootstrap 按轨迹或场景聚类，避免把相邻帧当独立样本。

初始验收目标：在预登记有效区且可见目标上横向 P95≤0.5 m、纵向 P95≤1 m、车道准确率≥98%、定位覆盖率≥90%。这些是候选目标，不是当前成绩。边界车道模糊、被排除目标和模糊匹配都单独列出。正式阈值应在封存测试前冻结。

## 6. 当前实测（开发片段 / proxy）

160 帧；2450 个符合投影像素条件的真值对象帧（含可能遮挡），1523 个 confirmed observed 对象帧，1520 个图像域匹配，1410 个匹配且已定位对象帧。

横向绝对误差 P95=0.2395 m，纵向=1.1074 m；三维尺寸相对误差混合 P95=38.73%。这些条件样本有选择偏差，不能外推为整段召回率或最终精度。尺寸与远处定位是下一阶段重点。连续代理关联 ID 变化为 0，并非正式 IDSW=0。
