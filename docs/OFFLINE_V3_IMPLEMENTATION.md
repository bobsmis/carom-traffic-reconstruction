# Offline V3：轨迹生命周期与离线一致性修复

## 范围与验收

这是一轮实际代码修复，不是 CAROM 全量复现或正式精度验收。原始素材仍使用假定焦距、四组名义道路坐标；没有同场景实测 K、测绘路面点或独立车道真值。

验收约束：纯本地检测与几何计算；保留源视频、掩膜、ID 与版本；预测显式标注；不强制车辆贴线、不移动车辆来消除重叠；平滑前后逐帧 ID 集合相同；误差与缺项如实记录。

## 已落地

1. **生命周期**：连续 3 次检测才确认；未确认对象保存在 `tentative_objects`，计入候选守恒而非静默丢弃。确认后漏检最多保留 18 帧，超过才退役；ID 永不复用。未确认对象丢失超过 1 帧退役。
2. **短时重关联**：已有掩膜/光流/Hungarian 关联基础上，加入局部 HSV 外观、尺寸和预测位移门限。颜色相似不是身份真值；不宣称解决所有遮挡和 ID 切换。
3. **离线 RTS**：对同 ID 的连续已定位片段，使用实际接受的体积框位置观测重建四维位置/速度状态，再前向滤波、后向平滑。没有把旧滤波坐标当成独立观测。朝向在速度信噪比足够时取平滑速度方向，静止时保留证据朝向。不跨长间断造轨迹，不添加检测，不补造首次有效定位前的世界坐标。
4. **尺寸与显示**：沿用每 ID 稳健初始化后锁定尺寸；量测/预测使用相同不透明度。横纵轴统一比例，1 米网格。尺寸稳定不是体积测量准确。
5. **标定门禁**：检查 K、共线/重复控制点、独立校验点格式与重用、控制点及校验点重投影误差。当前素材的 strict 校验仍不通过，实验输出保留显著警示。
6. **可追溯**：记录原始检测 `detections.jsonl`、逐帧状态、输入/模型/代码哈希与核心代码快照。平滑后保留 `online_estimate`、量测使用标记和修正量。

## 本次真实素材结果

本地 YOLO 新推理 240 帧，约 8 秒；最终重放使用该次检测缓存，忽略缓存中任何旧 ID/位置/车道/尺寸字段。缓存保留检测裁剪截断标志。

同一生命周期输出的平滑前后对比：

|指标|平滑前|平滑后|
|---|---:|---:|
|位置二阶差分模长 P95，名义 m/s²|119.36|2.83|
|朝向帧间变化 P95|1.161°|0.311°|
|发布的不同 ID|37|37|
|已定位对象—帧|3457|3457|
|占地框相交 >0.1 m² 的车辆对—帧|18|18|

平滑处理 31 个片段、3418 个对象—帧。上述数值是平滑性和工程一致性，不是实测速度、真实加速度或定位精度。离线相对在线位置修正 P95 约 1.35 名义米，务必结合原视频核验。投影轮廓 IoU 中位数约 0.813→0.816，P10 约 0.656→0.649，说明平滑并非逐帧视觉拟合全面提升。

## 尚未解决，不进入准确复现验收

- 标定控制点 RMSE 约 13.83 像素，无独立校验点；真实车道对应、尺度压缩和跨线误判依然未验证。模板只列待采集数据，不自动生成“实测点”。
- 仍有重叠。平滑不是碰撞修复；应进一步检查掩膜归属、遮挡和三维体积框拟合，在有效标定下对照真值。
- 仍有 768 个待定位对象—帧；遮挡/图像截断/方向证据不足的对象不在 BEV 伪造位置。车辆首次进入有效检测区或完成定位后出现是有记录的状态切换。
- 假定平面投影中的树木、建筑、车身会拉伸；这些不是道路平面。中值背景也可能留有车辆残影。它不等同于同场景正射地图。
- 尚未获得作者训练权重、完整经验修正规则及 GPS/无人机参考轨迹；本实现使用 YOLO、支持平面拟合和工程扩展 RTS，并非作者源码逐行复现。

```bash

.venv/bin/python scripts/run_carom_method.py --max-frames 240 --experimental-calibration --output outputs/NEW-ONLINE --video
.venv/bin/python scripts/smooth_carom_offline.py outputs/NEW-ONLINE outputs/NEW-OFFLINE
.venv/bin/python scripts/verify_carom_method.py outputs/NEW-OFFLINE
.venv/bin/python scripts/export_method_mobile.py outputs/NEW-OFFLINE

```
