# 扩大测量范围与按身份固定车体尺寸

## 用户所说的“置信区间”

本次调整的是图像/道路上的**有效测量区域**，不是统计学意义的置信区间。道路纵向从 0–50m 扩为 0–100m；横向从 -14..14m 扩为 -18..18m，覆盖八条名义车道及两侧余量。相机水平距离限制从 75m 放宽到 150m，条件投影误差敏感性上限从 0.75m 放宽到 2.5m，防止旧隐含门槛抵消扩大区域的效果。最小像素尺寸和掩膜面积限制保留。

这不是提高了远端精度，而是接受更大测量不确定性以增加覆盖。米制区域仍依赖尚未实测验证的标定。八车道模型及边距也尚非同场景测绘结论。

## 为什么原来体积变化

旧代码每次 `fit_cuboid` 都求新的长宽高，随后执行 `0.85 × 上帧尺寸 + 0.15 × 本帧尺寸`。这只平滑，不约束物体刚性：分割轮廓一变、车体遮挡、远处像素量化、子类别先验变化或航向不稳定，尺寸估计便继续漂移。俯视图直接用这些数值画底面，因此出现伸缩。

**车在视频里越来越大是透视变化；同一车辆在等米制 BEV 中的实际长宽不应随距离变化。** 航向旋转时的屏幕轴对齐外接宽高变化则是另一件事，不应通过锁死航向来掩盖。

## 新策略

1. 每个全局 ID 独立维护 `VehicleSize`。首次有效拟合给出暂定尺寸；收集期间尺寸保持不变，不按逐帧类别变化重置。
2. 收集高质量几何观测：轮廓凸包 IoU≥0.75、支撑平面 RMSE≤0.20m、支撑矩阵秩≥5。窗口最多36个接受样本，至少12个在相对中位数15%范围内的样本才确定尺寸中位数目标。
3. 从暂定值到目标值只做一次缓慢校正，每个接受帧每维最多变化1%。到达目标后按 ID 锁定，后续不再更新长宽高。
4. 有限失联预测继续使用原尺寸。姿态/位置失败、重新关联或单帧类别跳变都不重设尺寸；ID 退役后新身份独立初始化。
5. 固定尺寸送回体积框求解：同样的轮廓支撑平面，只拟合地面中心两个平移参数，再更新位置滤波。检测叠加图、速度估计和 BEV 共用这份形状，不只是锁住绘图贴图。
6. 更新先作用于临时副本，通过拟合质量、测量区与位置创新检查才提交；失败帧不污染尺寸证据。原始逐帧自由尺寸拟合保存到 `raw_size_fit`，与公开的固定尺寸分开审计。

`size_stabilization.state`：`provisional`（暂定）、`settling`（一次性缓慢校正）、`locked`（锁定）。公开 `dimensions_lwh` 是整个链路共同使用的尺寸。

扩区测试还发现远端同一掩膜同时得到 bus/truck 等标签的情况。新增进入跟踪前的类别兼容掩膜去重（凸包 IoU≥0.72，优先保留置信度更高的候选），避免同一视觉证据产生两个 ID 和两套体积。每条去重记录均标为 `duplicate_instance_mask`，保留候选来源及重叠值；这不是按 BEV 碰撞删除车辆。

## 验证

- 单元测试：锁定后尺寸噪声不影响输出、初期保持固定、校正速率上限、低质量观测不锁定、不同 ID 独立、被拒绝副本无副作用、固定尺寸条件下恢复已知位置。
- 场景测试：在道路纵向 0/25/50/75/100m 处，八条名义车道中心均通过区域/距离/敏感性门控。并不跳过像素与遮挡检查。
- 独立验证脚本：逐帧断言锁定后尺寸严格一致，校正期变化不超过约定速率；仍检验同一相机投影和地面位置合法性。

**固定尺寸解决的是时序一致性，不是体积真值认证。** 暂定值、类别尺寸先验、相机假设或误关联仍可能导致稳定但不准确的体积；仍需后续实测尺寸和标定检验。
